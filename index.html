一、我们如何收集和使用信息

1. 本地游戏运行

当前游戏没有将游戏存档主动上传到工作室服务器的接口。为提供游戏体验，程序会在您的设备或平台提供的本地存储空间处理以下数据：

  • 游戏存档：角色等级与属性、楼层、装备与物品、源素、锻造、图鉴、任务、系统邮件状态和兑换记录等，用于保存及恢复进度。
  • 时间与版本记录：最近活动时间、离线结算时间及暂停状态、存档版本与迁移备份等，用于离线收益结算、防止重复结算及旧档兼容。
  • 显示偏好：角色形象、减少动态效果等设置。角色形象选择不是对您真实性别的采集。
  • 窗口及操作信息：窗口宽高、安全区域、触摸位置及前后台切换事件，用于屏幕适配和游戏操作，不作为行为分析日志上传。

TapTap 版本使用平台的窗口信息和本地存储接口；兼容情况下使用系统信息接口返回的窗口及安全区域字段。浏览器版本使用视口信息和 localStorage。当前游戏不建立设备身份档案，不读取 IMEI、OAID、IDFA 等设备广告标识符。

2. 您主动联系我们时

当您通过邮箱或邮寄反馈问题、提出信息权利请求时，我们会接收您主动提供的联系信息、问题描述，以及您自行附上的截图或材料，仅用于回复、定位问题和处理请求。请尽量不发送身份证号码、密码、验证码或与问题无关的个人信息；截图可先遮挡无关内容。非必要材料由您自行选择是否提供。

3. 功能与权限范围

当前游戏自身不要求填写手机号、密码、真实姓名或身份证号码，不提供充值支付，不主动申请摄像头、麦克风、通讯录、精确位置、相册或剪贴板权限。本地存档接口不等于读取设备中的其他文件。

TapTap 客户端自身的权限和数据处理与本游戏代码不同。若平台为登录、实名、防沉迷等服务要求提供信息，请查看平台当时的提示和政策。当前游戏代码不读取您的平台实名资料、头像、昵称或登录凭据。

4. 处理依据与目的限制

我们仅在提供您请求的服务所必需、取得有效同意、履行法定义务或其他法律允许的范围内处理信息。涉及敏感个人信息、对外提供或其他需要单独同意的情形时，依法履行相应义务。不会将反馈信息用于营销或广告画像；改变用途或增加范围时，会依法另行告知并取得必要授权。

二、我们如何保存信息

游戏存档主要保存在您所使用设备的本地存储空间。当前未提供工作室运营的云端备份或跨设备同步。清理应用或浏览器数据、卸载应用、设备故障可能导致存档丢失，具体保留情况也受宿主平台和系统设置影响。

游戏内“删档重来”会重置当前角色进度，但保留显示偏好及已有的旧版迁移备份，不等于清除全部本地数据。完整清理方式见第七部分。

反馈与往来记录仅在解决问题、处理请求及法律要求所需的期限内保留；目的完成且没有继续保留的必要或法定义务时，予以删除或匿名化处理。您也可提前提出删除请求。

本网页托管在 GitHub Pages，联系邮箱使用 Gmail。网页技术日志，以及发送邮件时的邮箱地址、正文和附件，可能由服务商在境外基础设施中处理或保存。因此，我们不承诺这些数据均存储在中国境内。访问网页不触发游戏存档上传；发邮件也不会自动附带存档。不希望通过 Gmail 提交材料时，可使用第十部分的邮寄渠道。涉及我们依法应履行的个人信息跨境处理义务时，我们将依法履行，本段提示不替代法定程序或单独同意。

三、我们如何使用 Cookies 和同类技术

本政策网页不设置分析或广告 Cookies，不嵌入统计脚本、第三方字体、视频或追踪像素，不使用网页表单收集信息。

浏览器游戏使用 localStorage 保存进度，TapTap 版本使用平台本地存储。这些技术用于存档和偏好保存，不用于跨站追踪或广告推荐。禁用或清理存储会影响进度保存。托管平台及 TapTap 客户端可能根据各自政策处理技术信息，详见第五部分。

四、我们如何共享、转让、公开披露信息

我们不出售个人信息，不将本地游戏存档提供给广告商或数据交易方。除提供您请求的服务所必需且依法履行告知等义务、取得有效授权或法律明确要求的情形外，不向其他公司、组织或个人提供您的个人信息。

网站托管和邮件服务涉及的处理见第五部分。若将来另行委托第三方处理个人信息，我们会按法律要求约定处理目的、期限、方式、信息种类与保护措施，并监督受托方，不以“第三方服务”为由免除自身责任。

若合并、收购或资产转让涉及个人信息转移，我们会依法告知接收方名称或姓名及联系方式，并要求其继续履行保护义务；变更原处理目的或方式时，依法重新取得同意。

我们原则上不公开披露个人信息。如确需公开披露，将依法取得单独同意，或依据明确的法律规定办理。对于依法提出的披露要求，会核验依据并限于必要范围。

五、第三方产品或服务如何处理信息

提供方：易玩（上海）网络科技有限公司。本游戏使用其小游戏运行环境及画布、图片加载、触摸、窗口信息、前后台事件和本地存储能力，没有另外接入 TapSDK 登录、广告、支付或统计分析模块。

TapTap 为自身服务可能处理账号及认证信息、设备与网络信息、使用记录等，具体取决于您使用的平台功能和授权，不表示本游戏取得这些信息。请阅读 TapTap 隐私政策，通过平台渠道管理平台账号和权限。

2. GitHub Pages 网页托管

提供方：GitHub。访问本网页时，GitHub Pages 会出于安全目的记录访问者 IP 地址。相关技术信息的处理请参阅 GitHub 隐私声明及 GitHub Pages 数据收集说明。本页不会向 GitHub 提交您的游戏进度。

3. Gmail 联系邮箱

提供方：Google。仅当您选择发邮件时，邮箱地址、正文、附件及邮件传输所需信息会经电子邮件服务处理。详情参阅 Google 隐私政策。我们只将收到的内容用于处理您的联系事项；您可以改用邮寄方式。

网页托管和邮件服务不是嵌入游戏的广告或分析 SDK。将来接入新的 SDK 或服务并产生新的信息处理活动时，会在启用前更新说明并履行必要的告知和授权程序。

六、我们如何保护信息

我们遵循合法、正当、必要原则限制信息处理范围。当前游戏不设置工作室侧玩家存档上传接口，通过存档校验、保存失败提示等措施降低误覆盖风险。本地存档不是加密保险箱，设备共享、系统备份或他人取得设备访问权限可能影响数据安全，请妥善保管设备。

对于您主动提供的反馈信息，我们仅在处理事项所需范围内使用，不公开发布未经必要处理的个人信息。互联网和设备环境不能保证绝对安全，但这不免除我们依法应承担的信息保护责任。

如发生个人信息泄露、篡改或丢失等安全事件，我们将依法采取补救措施，根据事件情况向主管部门报告、向受影响用户告知事件影响、已采取措施和防范建议。

七、您如何管理信息

1. 查看、调整和复制

您可以在角色、背包、任务、图鉴、信箱等页面查看游戏记录，在设置中调整角色形象和显示偏好。对于提交给我们的个人信息，可通过第十部分的联系方式申请查阅、复制、更正或补充。当前没有云存档，我们无法远程读取或导出仅保存在您设备上的数据，也不会要求您上传无关内容。

2. 重置和删除

从游戏菜单进入设置，选择“删档重来”并确认，可重置当前角色等级、装备、源素、材料、任务等进度。此操作保留显示偏好和旧版迁移备份。如需删除全部本地游戏数据，请使用宿主平台的小游戏数据清理功能（如有），或在浏览器设置中清除游戏站点数据。若平台没有单独清理入口，请联系平台客服；清除整个应用数据可能影响其他游戏，请谨慎操作。

对于您主动提供给我们的信息，可以申请删除。若因法定保存期限或技术原因暂时不能立即删除，我们会说明原因，并依法停止除存储和必要安全保护之外的处理。

3. 撤回授权和账号事项

您可以停止使用游戏，通过设备或平台设置管理授权，或联系我们撤回基于同意开展的处理。撤回不影响撤回前处理行为的效力，也不影响依法无需以同意为基础的必要处理。当前没有工作室侧注册账号，因此没有单独的游戏账号注销流程；TapTap 账号注销和平台实名信息等事项，请通过平台渠道办理。

4. 请求响应

您还可要求解释本政策、对相关处理提出异议或投诉。我们将在收到请求后十五个工作日内回复；如需核验身份，仅要求与请求相称的必要信息。合理请求原则上免费。如依法无法满足，会说明具体原因和可用的救济途径。

八、我们如何处理未成年人的信息

未成年人应在监护人指导下阅读本政策，并依适用法律及平台要求使用服务。当前游戏自身不收集实名和年龄信息，不代表可以绕过平台实名或防沉迷限制。

不满十四周岁未成年人的个人信息属于敏感个人信息。若涉及此类信息的处理，我们将依法取得监护人同意，制定相应保护规则，并限于明确、必要的目的处理。请监护人代为提交涉及儿童的反馈，避免儿童直接发送不必要的身份资料。

监护人如发现未成年人未经适当授权向我们提供个人信息，可联系我们，我们会依法核实并采取删除等必要措施。

九、本隐私政策如何更新

我们会根据实际功能或法律要求更新本政策，在本页标明更新及生效日期。处理目的、方式、信息种类、第三方接收方或权利行使方式等发生重大变化时，将通过适当的显著方式告知，并依法取得所需同意，不以继续使用作为所有新增处理的默认授权。

更新不会不当地减损您的法定权利。历史版本可通过本页所在公开仓库的 版本记录查阅，也可通过邮箱向我们索取。
